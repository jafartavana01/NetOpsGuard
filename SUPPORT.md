# Support

For NetOpsGuard installation, TACACS+ policy, RADIUS, Active Directory integration, Cisco security auditing, and NCM questions:

1. Review the [README](README.md), [FAQ](docs/faq.md), and [troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Search [existing issues](https://github.com/jafartavana01/NetOpsGuard/issues).
3. If you still need help, [open an issue](https://github.com/jafartavana01/NetOpsGuard/issues/new/choose) with the affected commit/release, Ubuntu version, device and daemon context, expected versus actual results, and sanitized diagnostic output.

This is a community-maintained project. Support and response times are not guaranteed.

**Security vulnerabilities:** Do **not** disclose exploit details in public issues. Follow [SECURITY.md](SECURITY.md) to request private reporting.

**Sensitive information:** Never upload passwords, shared secrets, private keys, live database dumps, production device configurations, directory bind credentials, licence contents, or identifying customer information.
